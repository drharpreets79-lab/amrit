WHONET software-focused PubMed collection - deep re-search
Search/audit date: 2026-08-14

SCOPE
-----
This collection contains the 21 PubMed-indexed papers identified in the software-focused WHONET/WHONET-SaTScan/BacLink set (papers centred on the software, implementation, adoption, surveillance architecture, outbreak detection, or direct software evaluation/comparison). It is NOT the much larger set of papers that merely used WHONET as an analysis tool.

RESULT OF THE DEEP PDF SEARCH
-----------------------------
PubMed records audited: 21
Actual PDF files successfully retrieved, validated, and bundled: 13/21 (61.9%)
Additional records for which a lawful/public full-text or PDF route was verified, but the host/runtime blocked automated PDF-byte transfer: 6/21 (28.6%)
Total records with a verified lawful/public full-text route: 19/21 (90.5%)
Records still access-controlled or without a lawful open repository PDF confirmed: 2/21 (9.5%)
